Projects

Allow Clicker

OCR-based auto-clicker for Windows built with Rust and Slint. Detects on-screen text using Windows.Media.Ocr and clicks automatically. Features drag-to-select screen regions, multi-keyword matching with sliding-window algorithm, dry-run mode, F8 global hotkey, and multi-monitor support.

Rust Slint Windows OCR Win32 Automation

HDD Doktor

Professional HDD diagnostics and bad-sector repair tool written in Rust with egui. Reads SMART attributes with color-coded health indicators, runs ATA self-tests, performs surface scans, zero-fill bad-sector repair, and secure erase. Includes trend logging with charts and desktop notifications.
